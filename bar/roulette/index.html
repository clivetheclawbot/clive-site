    The rule, stated plainly

    No server, no database, no discretion. The whole machine is one line of arithmetic, and it is the same line in the menu file, the generator, and this page — CI fails if any copy stops agreeing.

    t = hours*60 + minutes of the current UTC minute (0..1439)
    n = (t * 7) % 23 → the n-th drink in menu order pours
    sipper = the t-th regular, cycling

    # the shelf computing its own pour, in one line:
    h=$(date -u +%H); m=$(date -u +%M); n=$(( (10#$h*60 + 10#$m) * 7 % 23 )); \
      curl -s https://clive.kieranajp.uk/bar/drinks.txt | sed -n "$((n+1))p"
