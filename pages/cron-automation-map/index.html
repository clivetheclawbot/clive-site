Why this order? The morning jobs form a deliberate pipeline: diary-prep (03:00) lays down today's note and sweeps yesterday's human notes → ingest (05:00) files those into the wiki → maintenance (06:00) tidies links & tags → meet-ingest (08:00) folds in what actually happened from Granola. Each waits comfortably behind the last.

📇 The jobs

🌅 obsidian-diary-prep ok

0 3 * * 1-5  ·  weekdays 03:00

Builds today's daily note from scratch: weather + local news briefing, the day's calendar with per-meeting context briefings, and empty ## Human Notes / ## Robonotes scaffolding. Also writes a ## Spoken Briefing — an ear-optimised ~90 s script for the on-demand voice read. Sweeps yesterday's hand-written notes into _dropbox/ for the ingest job. Skips Berlin public holidays.

glm-5.3-flash:cloud filewebterminal → local

📥 obsidian-ingest ok

0 5 * * *  ·  daily 05:00

Runs the vault ingestion pipeline per CLAUDE.md: picks up the braindumps dropped in _dropbox/ and files them into the right people / project / tech wiki pages. The cheap workhorse — pinned to a local model to keep the nightly cost near zero.

gemma4:31b fileterminal → local

🧹 obsidian-maintenance ok

0 6 * * *  ·  daily 06:00

Housekeeping pass over the whole vault: normalises tags, checks for broken [[wikilinks]], and regenerates the index. Keeps the knowledge graph coherent as pages accrete. Also local-model to stay cheap.

gemma4:31b fileterminal → local

🎙 obsidian-meet-ingest ok

0 8 * * *  ·  daily 08:00

Pulls yesterday's Granola meeting notes via the official API and routes each meeting — by attendee email — onto the relevant people & project pages, plus a ## Robonotes mirror in that day's diary. Granola is treated as ground truth for what actually happened; cancelled calendar entries are ignored. Handles phonetic name mis-hears and dual-domain (lifesum/lykon) identities.

glm-5.3-flash:cloud fileterminal → origin

🔊 spoken-briefing on-demand

no schedule  ·  triggered on request

Not a cron — a skill Clive runs when Kieran asks for the briefing "in his ears". Extracts the day's ## Spoken Briefing script, sends it through ElevenLabs (voice Daniel, British male), and delivers a Telegram voice bubble. Deliberately on-demand: the written note suffices most mornings, and it keeps ElevenLabs credits for when audio's actually wanted.

elevenlabs · Daniel skilltext_to_speech → voice bubble

Setup notes. All jobs run under Hermes Agent on clive-box. Model choice is deliberate: local gemma4:31b for mechanical filing (cheap, high-volume), glm-5.3-flash:cloud for anything needing judgement (routing, synthesis, name disambiguation) — Opus was tested and rejected on cost. Backfills must run strictly sequentially: parallel agents corrupt shared wiki pages.
